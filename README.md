# Xat amb Socket.IO

Xat en temps real fet amb Node.js, Express i Socket.IO.

## Requisits
- Node.js

## Instal·lació i execució
1. `npm install`
2. `node app.js`
3. Obre `http://localhost:3005` en dues pestanyes.

## Ús
Introdueix un nom (màxim 20 caràcters) i escriu missatges (màxim 500).
Els missatges arriben a totes les pestanyes sense recarregar.
